## About Me

- IT apprentice at **Arco IT Security Services** in Zürich
- Security enthusiast: I like understanding how systems break, so I can build them more resilient
- Day to day I administer and harden **Microsoft 365, Entra ID, Intune / Azure** and **Windows** environments
- Comfortable on **Linux**: servers, networking, NAS and self-hosted setups
- Run **security awareness** and phishing simulation campaigns for clients
- Practicing offensive security in labs (**Hack The Box**, home lab) on the way to **OSCP**
